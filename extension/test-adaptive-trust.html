Personal Adaptive Trust

Use this page to test TrustTrace AI’s local personal trust model. The feature is user-controlled and stores only domain-level metadata in Chrome local storage for this browser.

What it stores

Domain only

Example: example.com. Full URL paths and query strings are not stored.

Scan counts

Total, safe, caution, and high-risk scan counts for a domain.

User feedback

Trusted marks, suspicious marks, and false-positive reports on this device only.

Small adjustment

A bounded local trust adjustment from -15 to +10.

What it never stores

  • Full browsing history.
  • Full page text.
  • Passwords, emails, clipboard content, form values, cookies, tokens, or private messages.
  • Screenshots or image binaries.

How to test

  1. Open the TrustTrace popup and turn on Personal Adaptive Trust.
  2. Scan a safe official site such as https://www.apple.com several times.
  3. Mark the current domain trusted on your device.
  4. Scan again and look for an adaptive trust signal.
  5. Mark the domain suspicious and scan again to observe a negative learning signal.
  6. Click Reset Personal Learning to clear local learning metadata.

Safety rule

Personal Adaptive Trust cannot turn known-bad URLs, high-confidence visual clones, typosquatting, credential phishing, suspicious sender identity, clipboard/recovery phrase risks, or strong brand impersonation into safe results.

Personal vs community

One user report affects only that user's local browser. It does not change TrustTrace reputation for everyone.

Future community reputation should require many independent reports, rate limits, deduplication, and abuse checks before any global signal is considered.
